## What the website offers

- **Live validator data** for every network we run: status, commission, voting power, rank, uptime and estimated APR, read from the chains themselves.
- **Staking**: a direct path from each network page to our validator in the explorer, where you delegate from your own wallet. We never hold your keys.
- **Public endpoints** per network (RPC, REST, gRPC, WebSocket), with live status checks, peers and seeds, and an automatic fallback to [Cosmos Directory](https://cosmos.directory) when one of ours is down.
- **Node operator tools**: snapshots, state sync, install guides, a CLI reference, upgrade guides and a script generator.
- **Docs**: staking, wallet setup, using our endpoints, and a FAQ.
- **Infrastructure**: where our nodes run (country and hosting provider) and the IBC channels of the networks we validate.
- **Rewards calculator** per network.
